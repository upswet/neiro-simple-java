Ключевые моменты реализации:
FastText = Word2Vec + n-граммы
Вектор слова = сумма векторов его n-грамм
При обучении градиент распространяется на все n-граммы слова одинаково
OOV слова могут быть представлены через известные n-граммы
Используйте хеширование для экономии памяти на больших корпусах

1. ОСОБЕННОСТИ FASTTEXT VS WORD2VEC
Word2Vec:

Каждое слово = один вектор

"Собака", "собаки", "собаке" = разные векторы

Неизвестные слова = проблема

FastText:

Каждое слово = сумма векторов его подстрок (n-грамм)

"Собака" = сумма n-грамм: <со, соб, оба, бак, ака, ка>

Неизвестные слова = можно построить из известных подстрок




Пошаговый Алгоритм FastText (Skip-gram model)
Рассмотрим на примере самой популярной архитектуры Skip-gram (предсказывание контекстных слов по целевому).

Шаг 1: Подготовка и Создание Словаря N-gram'ов

Имеется текстовый корпус. Задается минимальная (minn) и максимальная (maxn) длина n-gram'ов (например, minn=3, maxn=6).

Для каждого слова в корпуса генерируется набор всех символьных n-gram'ов заданной длины, а также добавляется само слово как целое.

Важно: К слову добавляются специальные граничные символы <>, чтобы выделить начало и конец. Это помогает отличать аффиксы.

Пример для слова "apple" с minn=3, maxn=6:

Добавляем границы: "<apple>"

Извлекаем все 3-6 граммы символов:

3-gram: <ap, app, ppl, ple, le>

4-gram: <app, appl, pple, ple>

5-gram: <appl, apple, pple>

6-gram: <apple, apple>

Также добавляем само слово как <apple>.

Итоговое представление слова: ["<apple>", "<ap", "app", "ppl", "ple", "le>", "<app", "appl", "pple", "ple>", "<appl", "apple", "pple>", "<apple", "apple>"].

Создается общий словарь всех уникальных n-gram'ов по всему корпусу. Его размер может быть порядка 1-3 миллионов, что намного больше словаря уникальных слов (~100k-1M).

Шаг 2: Инициализация Векторов

Каждому уникальному n-gram'у из этого большого словаря случайным образом присваивается начальный вектор фиксированной размерности (например, 100 или 300 измерений). Векторы для целых слов (например, <apple>) — это тоже просто векторы их "корневого" n-gram'а.

Шаг 3: Процесс Обучения (Стохастический Градиентный Спуск)

Алгоритм проходит по корпусу, беря целевое слово (w_t) и окно контекстных слов вокруг него (например, [w_{t-2}, w_{t-1}, w_{t+1}, w_{t+2}]).

Цель: Настроить векторы так, чтобы по целевому слову можно было предсказать слова его контекста.

Получаем вектор целевого слова:

Для слова w_t ("apple") берем список всех его n-gram'ов (как в шаге 1).

Вектор слова V("apple") вычисляется как сумма векторов всех его n-gram'ов:
V("apple") = vector("<apple>") + vector("<ap") + vector("app") + ... + vector("apple>").

Это ключевое отличие от Word2Vec, где у слова один готовый вектор.

Делаем предсказание:

Этот агрегированный вектор V("apple") подается на выходной слой (обычно иерархический softmax или negative sampling, как в Word2Vec).

На выходном слое вычисляется вероятность для каждого слова в словаре (слов, а не n-gram'ов!) быть контекстным словом для "apple".

Сравниваются полученные вероятности с истинным контекстом (например, ["fruit", "red", "tree"]). Вычисляется ошибка (лосс).

Обратное распространение ошибки (Backpropagation):

Вычисленный градиент ошибки распространяется назад и обновляет не один вектор, а все векторы n-gram'ов, из которых состояло целевое слово.

Также обновляются веса выходного слоя (контекстных слов).

Если в контексте было слово "tree", то обновятся и его n-gram'ы ("<tr>", "tre", "ree", "ee>"...), когда оно станет целевым.

Шаг 4: Итерации и Результат

Процесс повторяется для миллионов примеров (пар [целевое слово, контекстное слово]) до схождения. В итоге мы получаем:

Векторы для всех n-gram'ов в словаре.

Вектор любого слова в обучающем корпусе можно получить на лету как сумму векторов его n-gram'ов.

Вектор для совершенно нового, незнакомого слова (OOV) можно получить тем же способом! Просто разбиваем его на n-gram'ы (с границами <>) и складываем векторы тех n-gram'ов, которые есть в нашем словаре.

Псевдокод (Упрощенный)
python
# Инициализация
for each ngram in global_ngram_vocabulary:
    vector[ngram] = random_vector(dim)

# Обучение
for target_word, context_word in training_pairs:
    # 1. Получить вектор целевого слова
    target_ngrams = extract_character_ngrams(target_word, minn, maxn)
    target_vector = sum(vector[ngram] for ngram in target_ngrams)

    # 2. Рассчитать ошибку предсказания контекстного слова
    loss = compute_loss(target_vector, context_word)  # e.g., via softmax

    # 3. Обновить векторы через градиентный спуск
    gradient = compute_gradient(loss)
    for ngram in target_ngrams:
        vector[ngram] -= learning_rate * gradient  # Обновляем каждый n-gram целевого слова
    # ... также обновляются веса для слов контекста
Ключевые Параметры и Особенности
minn, maxn: Длина n-gram'ов. Для латиницы часто 3-6, для иероглифов (китайский) используют 1-граммы символов.

Иерархический Softmax / Negative Sampling: Используются для ускорения обучения, как в Word2Vec.

Эффективность: Обучение медленнее, чем Word2Vec, из-за огромного количества n-gram'ов, но все равно очень эффективно.

Качество: Дает великолепные результаты на синтаксических задачах (аналогии) и особенно на семантических задачах для редких слов.

FastText для Классификации
Отдельно стоит модель FastText для классификации текстов. Ее алгоритм схож:

Весь документ (предложение, абзац) представляется как среднее векторов всех входящих в него слов (которые, в свою очередь, суммы n-gram'ов).

Этот усредненный вектор подается на линейный классификатор.

Простота и скорость делают его очень сильным baseline для задач классификации.

Итог: Алгоритм FastText гениален своей простотой и эффективностью. Он использует "мешок n-gram'ов" на уровне символов, чтобы создать надежные, морфологически осознанные векторные представления слов, которые работают даже с незнакомыми словами.
