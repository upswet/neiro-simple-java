Embedding (в переводе с английского — «вложение») — термин машинного обучения, который означает способ представления объектов (слов, предложений, изображений и других типов данных) в виде числовых векторов. Эти векторы позволяют нейронным сетям работать с различными типами данных и анализировать их взаимосвязи.
Главная задача эмбеддингов — превращать сложные данные в набор чисел, с которым удобно работать алгоритмам.

АЛГОРИТМ ПОЛУЧЕНИЯ ЭМБЕДДИНГОВ СЛОВ БЕЗ ГЛУБОКИХ БИБЛИОТЕК
1. ПОДГОТОВИТЕЛЬНЫЙ ЭТАП: ПОДГОТОВКА ТЕКСТА
Токенизация:

Разбиваем текст на отдельные слова (токены)

Удаляем знаки препинания, специальные символы

Приводим все к нижнему регистру

Построение словаря:

Собираем все уникальные слова из текста

Присваиваем каждому слову уникальный индекс (ID)

Создаем обратное отображение: ID → слово

Размер словаря (V) = количество уникальных слов

Создание One-Hot векторов:

Для каждого слова создаем вектор размерности V

Все элементы = 0, кроме позиции с ID слова = 1

Пример: словарь ["собака":0, "кошка":1, "бежит":2]

"собака" → [1, 0, 0]

"кошка" → [0, 1, 0]

2. ОСНОВНОЙ ЭТАП: ОБУЧЕНИЕ МОДЕЛИ ЭМБЕДДИНГОВ
Мы будем использовать нейронную сеть с одним скрытым слоем (автокодировщик):

Архитектура сети:
text
Входной слой: V нейронов (размер словаря)
       ↓
Скрытый слой: E нейронов (размер эмбеддингов) ← здесь будут эмбеддинги!
       ↓
Выходной слой: V нейронов (размер словаря)
Алгоритм обучения (автокодировщик):
Инициализация:

Создаем нейронную сеть с указанной архитектурой

Инициализируем веса случайными небольшими значениями

Цель обучения:

Научить сеть восстанавливать входное слово на выходе

Подаем на вход one-hot вектор слова

Ожидаем на выходе тот же one-hot вектор

Прямой проход для одного слова:

text
Шаг 1: word → one-hot вектор [1, 0, 0, ...]
Шаг 2: Входной слой просто передает этот вектор дальше
Шаг 3: Скрытый слой вычисляет:
       hidden = активация(веса_входные × input + смещение)
       (это и есть эмбеддинг слова!)
Шаг 4: Выходной слой вычисляет:
       output = активация(веса_скрытые × hidden + смещение)
Обратное распространение ошибки:

Сравниваем выход сети с ожидаемым one-hot вектором

Вычисляем ошибку (например, среднеквадратичную)

Обновляем веса сети, чтобы уменьшить ошибку

Повторение:

Проходим по всем словам в тексте

Повторяем много эпох (проходов по всем данным)

3. ИЗВЛЕЧЕНИЕ ЭМБЕДДИНГОВ
После обучения:

Матрица эмбеддингов - это веса между входным и скрытым слоем:

Матрица размером V × E

Каждая строка - эмбеддинг соответствующего слова

Альтернативный способ - использовать активации скрытого слоя:

Подаем one-hot вектор слова на вход обученной сети

Берем значения нейронов скрытого слоя (до активации или после)

Это и есть эмбеддинг слова

4. АЛЬТЕРНАТИВНЫЙ МЕТОД: SKIP-GRAM (Word2Vec-подобный)
Более сложный, но эффективный алгоритм:

Подготовка пар слов:

Для каждого слова в тексте берем его соседей в окне

Пример: "собака быстро бежит" при окне=1 даст пары:

(собака, быстро)

(быстро, собака), (быстро, бежит)

(бежит, быстро)

Архитектура сети:

text
Входной слой: V (размер словаря) нейронов
      ↓
Скрытый слой: E (размер эмбеддинга) нейронов ← эмбеддинги
      ↓
Выходной слой: V (размер словаря) нейронов (вероятности слов)
Обучение:

Подаем на вход one-hot вектор центрального слова

Обучаем сеть предсказывать one-hot вектор контекстного слова

ИЛИ обучаем предсказывать несколько контекстных слов

Получение эмбеддингов:

Веса между входным и скрытым слоем = матрица эмбеддингов

Веса между входным и скрытым слоем (матрица W1 размерности V x E) - это и есть матрица эмбеддингов для центральных слов.
То есть, после обучения каждая строка этой матрицы (соответствующая индексу слова) будет эмбеддингом этого слова, когда оно используется как центральное.
Веса между скрытым и выходным слоем (матрица W2 размерности E x V) можно рассматривать как эмбеддинги слов, когда они выступают в роли контекстных.
Однако обычно используют только матрицу W1 для эмбеддингов слов.

В Skip-Gram архитектуре есть две матрицы эмбеддингов:

Входной слой (V нейронов)
      ↓ W_in (V × E)  ← Матрица входных эмбеддингов
Скрытый слой (E нейронов)
      ↓ W_out (E × V) ← Матрица выходных эмбеддингов
Выходной слой (V нейронов)

КАК ОБУЧАТЬ ПРЕДСКАЗЫВАТЬ НЕСКОЛЬКО БЛИЖАЙШИХ СЛОВ?

Подход 1: Независимые пары (стандартный)

Предложение: "собака быстро бежит по парку"
Окно = 2 (2 слова слева, 2 справа)

Центральное слово: "бежит"
Контекстные слова: ["собака", "быстро", "по", "парк"]

Создаем 4 независимых примера:
1. (бежит → собака)
2. (бежит → быстро)
3. (бежит → по)
4. (бежит → парк)

Подход 4: Negative Sampling (эффективный путь)
Вместо предсказания ВСЕХ V слов, предсказываем только:
Позитивные примеры: реальные контекстные слова (несколько штук)
Негативные примеры: случайные слова не из контекста (обычно 5-20)

Для каждого центрального слова w:
  Для каждого контекстного слова c в окне:
    # Позитивный пример
    предсказать, что (w, c) — хорошая пара
    обновить веса

    # k негативных примеров
    для i от 1 до k:
      случайно выбрать слово n не из контекста
      предсказать, что (w, n) — плохая пара
      обновить веса


5. УПРОЩЕННЫЙ АЛГОРИТМ (ДЛЯ ПОНИМАНИЯ)
Пошагово:

text
Шаг 1: Подготовить текст
   - "Собака бежит быстро. Кошка спит."

Шаг 2: Построить словарь
   - {"собака":0, "бежит":1, "быстро":2, "кошка":3, "спит":4}
   - V = 5

Шаг 3: Создать one-hot векторы
   - "собака" → [1,0,0,0,0]
   - "бежит" → [0,1,0,0,0]
   - и т.д.

Шаг 4: Создать нейросеть
   - Вход: 5 нейронов
   - Скрытый слой: 3 нейрона (E=3)
   - Выход: 5 нейронов

Шаг 5: Обучить автокодировщик
   - Подаем "собака" → [1,0,0,0,0]
   - Ожидаем на выходе [1,0,0,0,0]
   - Обновляем веса
   - Повторяем для всех слов много раз

Шаг 6: Извлечь эмбеддинги
   - Берем веса между входным и скрытым слоем
   - ИЛИ подаем слово и берем активации скрытого слоя

Шаг 7: Результат
   - "собака" → [0.21, -0.34, 0.87] (пример)
   - "кошка" → [0.19, -0.31, 0.92]
   - "бежит" → [0.45, 0.12, -0.23]
6. КЛЮЧЕВЫЕ МОМЕНТЫ
Размерность эмбеддингов (E):

Обычно 50-300 измерений

Чем больше, тем больше деталей сохраняется

Но требует больше данных для обучения

Качество эмбеддингов зависит от:

Объема тренировочного текста

Размера окна контекста

Размерности эмбеддингов

Количества эпох обучения

Что происходит на самом деле:

Сеть учится представлять слова в сжатом виде

Слова с похожим значением получают похожие векторы

Синтаксические и семантические отношения отражаются в геометрии векторов

7. ВИЗУАЛИЗАЦИЯ ПРОЦЕССА
text
Текст → Токены → Словарь → One-Hot → Нейросеть → Веса скрытого слоя → Эмбеддинги
                   ↓                                         ↓
                [собака, кошка]                      [вектор_собаки, вектор_кошки]
8. ЧТО МОЖНО ДЕЛАТЬ С ЭМБЕДДИНГАМИ
Находить похожие слова (по косинусному сходству)

Решать аналогии: вектор(король) - вектор(мужчина) + вектор(женщина) ≈ вектор(королева)

Кластеризовать слова по смыслу

Использовать как вход для других NLP-задач

9. ОГРАНИЧЕНИЯ ПРОСТОГО АЛГОРИТМА
Один вектор на слово (не учитывает многозначность)

Не учитывает порядок слов в предложении

Требует много данных для качественных эмбеддингов

Не учитывает морфологию (разные формы одного слова - разные векторы)

Этот алгоритм - основа, на которой строятся современные модели типа Word2Vec, GloVe, FastText, но в упрощенном виде. В реальных системах используются оптимизации (negative sampling, hierarchical softmax) для ускорения обучения на больших корпусах.
