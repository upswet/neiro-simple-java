Помимо обычной точности (accuracy), в задачах классификации полезны метрики, которые учитывают дисбаланс классов или специфику требований. Вот несколько метрик, которые легко добавить в ваш проект, реализовав интерфейс Metric.

1. Precision (точность)
Доля правильно предсказанных положительных примеров среди всех предсказанных положительных.
Precision = TP / (TP + FP)
Полезна, когда важна минимизация ложных срабатываний (например, спам-фильтр).

2. Recall (полнота)
Доля правильно предсказанных положительных примеров среди всех истинно положительных.
Recall = TP / (TP + FN)
Важна, когда нельзя пропустить положительный случай (медицинская диагностика).

3. F1-score
Среднее гармоническое precision и recall:
F1 = 2 * (Precision * Recall) / (Precision + Recall)

4. Confusion Matrix (матрица ошибок)
Не скалярная метрика, но очень полезна для анализа ошибок.

5. Top-k Accuracy
Доля примеров, где правильный класс входит в k самых вероятных предсказаний. Полезна для задач с большим числом классов.

6. Log Loss (кросс-энтропия)
Уже используется как функция потерь, но можно добавить как метрику для мониторинга.

7. AUC-ROC (для бинарной классификации)
Площадь под ROC-кривой – качество ранжирования.

8. Mean Per Class Accuracy
Средняя точность по классам (полезна при дисбалансе).
