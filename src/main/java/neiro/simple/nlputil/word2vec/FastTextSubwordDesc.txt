Данный код представляет собой реализацию FastText — модели векторного представления слов, которая учитывает подсловную (subword) информацию через символьные n-граммы. Модель обучается методом skip-gram с negative sampling и включает в себя два важных улучшения: субсэмплинг частых слов и экспоненциальное затухание скорости обучения.

Ниже — подробный разбор того, что делает каждый компонент.

1. Основная идея FastText (subword)
В отличие от классического word2vec, где каждое слово имеет свой вектор «с нуля», здесь вектор слова формируется как сумма (усреднение) векторов его символьных n-грамм. Например, для слова «кот» при длинах n-грамм от 3 до 5 могут быть выделены <ко, кот, от>, <кот>. Благодаря этому модель способна:

строить векторы для слов, не встречавшихся в обучении (OOV),

лучше улавливать морфологию и общие корни слов.

2. Гиперпараметры (конструктор)
java
public FastTextSubword(int dim, double initialLr, double gamma, int window,
                       int minn, int maxn, int negSamples)
dim – размерность векторного пространства (например, 30).

initialLr – начальная скорость обучения.

gamma – коэффициент экспоненциального затухания lr (0 < gamma ≤ 1). Каждую эпоху lr = initialLr * gamma^epoch.

window – радиус контекстного окна skip-gram.

minn, maxn – минимальная и максимальная длина извлекаемых символьных n-грамм.

negSamples – число отрицательных примеров на один положительный.

subsamplingThreshold – порог для отбрасывания частых слов (по умолчанию 1e-5).

3. Построение словарей и инициализация (buildVocab)
Метод обрабатывает весь корпус и создаёт:

wordIndex – отображение слов в индексы выходной матрицы wo.

ngramIndex – отображение n-грамм в индексы входной матрицы wi.

Матрицы весов:

wo[wordCount][dim] – векторы слов (выходные), инициализируются случайными малыми числами.

wi[ngramCount][dim] – векторы n-грамм (входные).

Unigram-таблица – для быстрого сэмплирования отрицательных примеров согласно распределению частот слов в степени 0.75. Таблица размером 10 миллионов ячеек заполняется индексами слов пропорционально их частоте.

wordKeepProb – вероятности сохранения слова при субсэмплинге, вычисляемые по формуле sqrt(threshold / freq), если частота слова выше порога.

4. Субсэмплинг частых слов
В методе subsampleSentence каждое слово предложения с вероятностью 1 - wordKeepProb отбрасывается. Это снижает влияние чрезмерно частых слов (например, предлогов, союзов), перераспределяя градиент в пользу редких, более содержательных токенов.

5. Обучение на одном предложении (trainSentence)
Центральное слово пропускается через извлечение его n-грамм. Контекстные слова в окне радиуса window обрабатываются:

Положительный пример: для реального контекстного слова вычисляется скалярное произведение его выходного вектора wo[ctxIdx] и суммы векторов n-грамм центрального слова. Через сигмоиду получается предсказанная вероятность. Градиент вычитается из обоих матриц: wo обновляется с учётом текущего входа, а wi – с использованием старого значения wo (это соответствует обновлению по схеме skip-gram).

Отрицательные примеры: negSamples раз выбирается случайное слово из unigram-таблицы (не совпадающее с правильным). Цель – предсказать 0. Градиент обновляет веса аналогично, но с противоположным знаком в выражении ошибки.

Такой подход позволяет эффективно обучать модель без полного softmax по всему словарю.

6. Полный цикл обучения (train)
На каждую эпоху вычисляется убывающий currentLr.

Предложения корпуса пропускаются через субсэмплинг и затем через trainSentence.

Для контроля качества вычисляется среднее косинусное сходство по заданным аналогиям (типа «король – мужчина + женщина = королева»). Значение выводится в лог вместе с текущим lr.

7. Извлечение векторов слов и семантические операции
getWordVector(word) – усредняет векторы всех n-грамм слова. Работает даже для слов, которых не было в обучении.

getNearestWords(vector, N) – находит N ближайших по косинусному сходству слов к заданному вектору.

addVectors, subtractVectors, cosine – статические утилиты для векторной арифметики и измерения сходства.

8. Чтение корпуса (readCorpusFromDirectory)
Вспомогательный метод читает все .txt файлы из указанной директории. Каждая строка токенизируется: текст приводится к нижнему регистру, удаляются небуквенные символы, разбивается по пробелам. Получается список предложений – списков слов.

9. Демонстрация (main)
Демонстрационный пример:

Создаётся модель с указанными параметрами (dim=30, lr=0.02, gamma=0.95, окно=3, n-граммы от 3 до 6 символов, 5 отрицательных примеров).

Читается корпус из папки d:\Work\....

Строится словарь.

Запускается обучение на 10 эпох с мониторингом трёх аналогий (князь – мужчина + женщина и др.).

После обучения выводятся ближайшие слова к ряду запросов, результаты векторной арифметики и косинусные сходства.

Модель сериализуется через FileUtils.save.

Ключевые особенности реализации
Экспоненциальное затухание lr через gamma даёт более плавную сходимость, чем резкое обнуление.

Negative sampling реализован через unigram-таблицу со сглаживанием (степень 0.75), что соответствует оригинальной статье word2vec.

Субсэмплинг не только ускоряет обучение, но и повышает качество редких слов.

Вектор слова — усреднение n-грамм — позволяет получать представления для незнакомых слов.

Таким образом, код полностью реализует легковесную, но мощную модель FastText на Java, подходящую для обучения на небольших корпусах или в демонстрационных целях.
